# Покадровые пиксельные анимации

В проект добавлена отдельная система покадровой анимации для игрока и врага. Она не использует старые Animator Controller и не меняет физические коллайдеры персонажей.

## Набор анимаций

Для обоих персонажей создаются 7 состояний, 8 направлений и 6 кадров на направление:

- Idle — ожидание;
- Walk — ходьба;
- Run — бег;
- Shoot — выстрел;
- Reload — перезарядка;
- Hit — получение урона;
- Death — смерть.

Направления атласа: S, SW, W, NW, N, NE, E, SE.

## Импорт

При открытии Unity Editor скрипт `Assets/Scripts/Editor/PixelAnimationAtlasGenerator.cs` проверяет наличие атласов. Если они ещё не созданы, редактор генерирует два PNG-файла в `Assets/Resources/Animations`, настраивает Sprite Mode = Multiple и нарезает кадры. Для ручного повторного создания доступно меню:

`Tools → 2D Shooter → Создать пиксельные атласы анимаций`.

Генератор находится в папке Editor и не входит в игровой билд. Он создаёт только исходные ассеты в редакторе. Во время игры используются уже импортированные Sprite-кадры; новые текстуры, спрайты или игровые объекты анимационной системой не создаются.

## Подключение к персонажам

В `SampleScene` компонент `DirectionalSpriteAnimator` установлен на существующие корневые объекты `player` и `Enemy`. Компонент находит их уже существующий дочерний SpriteRenderer, поэтому новые игровые объекты не нужны.

Игрок выбирает направление по повороту к курсору, враг — по повороту к игроку. Ходьба и бег переключаются по скорости Rigidbody2D. Стрельба и перезарядка получают события из скриптов оружия, попадание и смерть — из систем здоровья.

## Проверка после открытия проекта

1. Открой проект в Unity и дождись окончания импорта атласов.
2. Проверь Console: не должно быть ошибок импорта или сообщений о ненайденных кадрах.
3. Открой `SampleScene`, выбери `player` и `Enemy`: на обоих должен быть `DirectionalSpriteAnimator`.
4. Запусти Play Mode: WASD проверяет ходьбу/бег, мышь — 8 направлений прицеливания, ЛКМ — стрельбу, R — перезарядку.
5. Проверь попадания и смерть врага: враг должен завершить анимацию смерти до удаления.

## Настройки Inspector

Поля C# имеют английские имена, русские подписи и русские подсказки через `InspectorLabel`. Для игрока используется `Animations/PlayerDirectionalAtlas`, для врага — `Animations/EnemyDirectionalAtlas`.
