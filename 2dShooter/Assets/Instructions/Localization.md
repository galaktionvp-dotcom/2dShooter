# Правила локализации Unity Inspector

## Назначение

Этот файл является постоянной инструкцией проекта для локализации пользовательских полей в Unity Inspector.

При добавлении или изменении собственных сериализуемых полей проекта необходимо соблюдать эти правила.

## Основное правило

Имена полей в C# должны оставаться на английском языке.

Название поля и подсказка в Unity Inspector должны отображаться на русском языке.

Для этого используется атрибут:

```csharp
[InspectorLabel("Название на русском", "Подсказка на русском.")]
[SerializeField] private float maxSpeed = 5f;
```

### Пример

Правильно:

```csharp
[InspectorLabel(
    "Максимальная скорость",
    "Максимальная скорость, с которой игрок может двигаться."
)]
[SerializeField] private float maxSpeed = 5f;
```

Неправильно:

```csharp
[SerializeField] private float максимальнаяСкорость = 5f;
```

## Что должно быть локализовано

Каждое пользовательское поле, которое показывается в Unity Inspector, должно иметь:

1. Русское название.
2. Русский tooltip.
3. Английское имя переменной в исходном C# коде.

Это относится в первую очередь к полям с `[SerializeField]` и другим пользовательским полям, которые специально выводятся в Inspector.

## Требования к tooltip

Tooltip должен кратко объяснять:

- что делает параметр;
- на что влияет его значение;
- при необходимости — единицы измерения или важные ограничения.

Пример:

```csharp
[InspectorLabel(
    "Время перезарядки",
    "Время, необходимое для полной перезарядки оружия, в секундах."
)]
[SerializeField] private float reloadTime = 1.1f;
```

Не следует использовать бессмысленные подсказки вроде:

```text
"Это настройка."
```

## Для новых скриптов

Если создаётся новый скрипт с настройками в Inspector, сразу подключай:

```csharp
using InspectorLocalization;
```

и используй:

```csharp
[InspectorLabel("Русское название", "Подробное объяснение параметра.")]
[SerializeField] private ...
```

## Существующая система

Система локализации находится здесь:

```text
Assets/Scripts/InspectorLocalization/
```

Основные файлы:

- `InspectorLabelAttribute.cs` — атрибут для русского названия и tooltip.
- `Editor/InspectorLabelDrawer.cs` — отображение локализованного названия и tooltip в Unity Editor.

## Важно для работы через ИИ

При изменении существующего скрипта не удаляй `InspectorLabel` с уже локализованных полей.

При добавлении нового пользовательского поля в Inspector добавляй русский `InspectorLabel` с русским tooltip сразу.

Не переименовывай английское имя C#-поля только ради локализации Inspector.

Локализация должна менять только отображение в Unity Inspector, а не API, имена переменных или логику игры.
